### 2.4 Authentication Action URL Safety Audit — **DEFERRED (Retain Default URL)**
- **Current URL:** `https://khadma-oran.firebaseapp.com/__/auth/action`
- **Proposed URL:** `https://khadma-oran.web.app/auth/action`
- **Audit of [src/pages/AuthAction.tsx](../../src/pages/AuthAction.tsx):**
  - `verifyEmail` & `resetPassword`: Implemented with StrictMode-safe promise deduplication, invalid/expired/reused error handling, FR/AR localization, and open-redirect-safe `resolveSafeReturnPath()`.
  - `recoverEmail` / `verifyAndChangeEmail` / `revertSecondFactorAddition`: **NOT supported** (returns `authAction.errorUnsupported`).
- **Decision:** Because Firebase applies a custom Action URL globally to all email templates, **retain `https://khadma-oran.firebaseapp.com/__/auth/action`** and classify custom Action URL cutover as **DEFERRED** until `recoverEmail` is implemented.

## 4. Escalation & Rollback Thresholds

- **Cost anomaly:** Any unexpected SMS spend, reCAPTCHA Enterprise spike, or MTD spend crossing **\$5 (50% alert)** -> inspect Auth SMS logs, App Check metrics, and Cloud Run invocation counts immediately.
- **Error spike:** Repeated `HTTP 5xx` or unhandled `ERROR` logs on `manageEmployerListing`, `adminManageMarketplace`, `getGigContactLink`, or `reportGigListing` -> inspect stack trace; if release-induced, execute the certified rollback in `docs/release/V1.4.1-PRODUCTION-RELEASE-CERTIFICATION.md` without weakening security rules.
- **Abuse / spam wave:** Toggle `requirePreApproval: true` in `/admin` (runtime toggle, no redeploy required) to hold new listings for manual approval.
- **Backup failure (Nov 29):** If `gcloud firestore backups list --project=khadma-oran --quiet` shows `0` backups on Monday, Nov 30, inspect Firestore Backup Schedule `136a0746-ab0f-438c-a3bf-b6e68ee61c2c` in GCP Console while PITR (7-day window) continues protecting data.
